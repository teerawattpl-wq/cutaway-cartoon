# ตัวอย่าง hello: ใครชนะรีโมต

เรื่องสั้นสามบรรทัดที่เล็กที่สุดซึ่งยังใช้ครบทุกส่วนของระบบ: ฉากห้องตัดขวางห้องเดียว ตัวละครสองตัว (ป้ากับแมวส้ม) กล้องที่เคลื่อนตั้งแต่เฟรมแรก คำบรรยายที่ตัดวลีตามเสียง การ์ดกฎหนึ่งใบ และชื่อท้ายตอน ไม่มีไฟล์เสียงมาให้ ต้องสร้างเอง

```
python kit/make_voice.py hello/lines.th.json hello/audio/th/narration-raw.wav     ใช้โควตาของคุณ 1 ครั้ง
python kit/words.py hello/audio/th/narration-raw.wav th                           ดูเวลาและคำที่ถอดได้
```

ตัดเสียงเป็นไฟล์ละบรรทัดที่กลางช่วงเงียบ แล้วบันทึกเป็น `hello/audio/th/lines/01.wav`, `02.wav`, `03.wav` จากนั้น

```
python kit/build.py hello th
python kit/storyboard.py hello th
cd hello/build/th && npx hyperframes snapshot --at 0.5,3,7,11 --no-end -o snaps
```

เปิดดู `film.js` เพื่อดูว่าส่วนต่างๆ ต่อกันอย่างไร สิ่งที่ควรเก็บไว้เป็นนิสัย: ทุกเวลาในภาพมาจาก `T` กล้องเริ่มเคลื่อนที่เฟรมแรก ท่าทุกท่าขึ้นกับเวลา และของที่ต้องสว่างตลอดต้องวาดหลังการปรับภาพ
