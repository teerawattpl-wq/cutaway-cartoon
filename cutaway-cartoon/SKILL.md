# การ์ตูนตัดขวาง

ใช้ได้ทุกแนวและทุกตัวละคร โดยใช้วิธีเล่าแบบเดียวกันทุกเรื่อง: ฉากใหญ่ฉากเดียว กล้องไม่ตัดภาพ และทุกอย่างวาดจาก `render(t)` ซึ่งเป็นฟังก์ชันของเวลา เฟรมแต่ละเฟรมถูกวาดสดบน canvas ไม่มีภาพนิ่งหรือวิดีโอสำเร็จรูป

สกิลนี้ครบในตัว มีโค้ดวาด ชุดเครื่องมือสร้างคลิป และขั้นตอนตรวจงาน ไม่ต้องติดตั้งสกิลอื่นเพิ่ม

ผู้ใช้เป็นคนดูการเคลื่อนไหวและฟังเสียง เอเจนต์ตรวจได้แค่ภาพนิ่ง จึงต้องบอกทุกครั้งว่าอะไรยังไม่ได้ตรวจ ถามทีละข้อพร้อมคำแนะนำหนึ่งข้อ

## เริ่มโปรเจกต์ (ทำครั้งเดียว)

จากโฟลเดอร์ของสกิลนี้ รัน `python tools/setup_project.py <โฟลเดอร์โปรเจกต์>` จะได้

- `kit/` เครื่องมือ: `build.py` `make_voice.py` `words.py` `pauses.py` `storyboard.py` `frame_sheets.py` และฟอนต์
- `shared/` โค้ดวาดที่ใช้ร่วมกัน ไฟล์ที่มีอยู่แล้วจะไม่ถูกทับ
- `hello/` เรื่องตัวอย่างสามบรรทัด อ่าน `hello/README.md` และ `hello/film.js` ก่อนเขียนเรื่องแรก

ตรวจเครื่องมือ: `python --version`, `ffmpeg -version`, `node -v`, `npx hyperframes --version` ถ้าไม่มี `python` ให้ใช้ `uv run --no-project --with numpy --with scipy --with pillow python ...` แทนทุกคำสั่ง

กุญแจสร้างเสียงอยู่ในไฟล์ `.env` ของโปรเจกต์เท่านั้น ห้ามเปิดอ่าน พิมพ์ หรือคัดลอกไปที่ไหน และเตือนผู้ใช้ให้ไม่ใส่ไฟล์นี้เมื่อแชร์หรือบีบโปรเจกต์ โควตาฟรีของ TTS มีจำกัดและบริการอาจใช้ข้อความที่ส่งไปปรับปรุงผลิตภัณฑ์ ให้บอกผู้ใช้ก่อนเรียกสร้างเสียงทุกครั้งว่าใช้ไปหนึ่งคำขอ

## ลำดับงานของหนึ่งตอน

ต้องให้ผู้ใช้อนุมัติ 3 จุด คือบท storyboard และการดูจริงตอนท้าย นอกนั้นทำต่อได้เลย

1. **หัวข้อและข้อเท็จจริง:** ถ้ามีตัวเลขหรือข้อเท็จจริงจริง ตรวจแหล่งก่อนเขียน ทำตารางแหล่งอ้างอิง และตัดสิ่งที่ยืนยันไม่ได้ออก เรื่องแต่งต้องระบุว่าแต่ง
2. **ใบสั่งงานสั้น:** แนวคิด กฎความต่อเนื่อง รายการที่ห้ามทำ และบทพร้อมรายการภาพต่อบรรทัด 6–11 บรรทัด ราว 70–90 วินาที ไม่ใส่เวลา เวลามาจากเสียงจริง รออนุมัติ
3. **เสียงพากย์:** เขียน `lines.th.json` (รูปแบบอยู่ใน `kit/make_voice.py`) แล้วสร้างทั้งบทในคำขอเดียว

   ```
   python kit/make_voice.py story01/lines.th.json story01/audio/th/narration-raw.wav
   python kit/words.py story01/audio/th/narration-raw.wav th
   ```

   `words.py` พิมพ์แต่ละคำพร้อมเวลาและช่วงเงียบยาว ตัดเสียงเป็นไฟล์ละบรรทัดที่กลางช่วงเงียบ (`ffmpeg -ss 0.00 -to 7.52 -i narration-raw.wav story01/audio/th/lines/01.wav`) TTS มักเพิ่มเสียงแปลก คำซ้ำ หรือประโยคท้ายที่ไม่อยู่ในบท เก็บเฉพาะที่ตรงกับบท และบอกผู้ใช้ทุกคำที่ถอดได้ต่างไป เพราะคำสั้นกับคำที่ต่างแค่วรรณยุกต์ต้องให้ผู้ใช้ฟังเอง เสียงต้องผ่านก่อนสร้างภาพ เพราะเวลาทุกอย่างมาจากเสียงนี้
4. **เส้นเวลา:** เขียน `story.json` แล้วรัน `python kit/build.py story01 th` ได้ `window.T` ที่มี `T.l3` (จุดเริ่มบรรทัด 3), `T.e3` (จุดจบ), `T.p3[1]` (วลีที่สองของบรรทัด 3) ห้ามพิมพ์วินาทีลงในภาพตรง ๆ และวลีอาจมีน้อยกว่าที่คาด ใช้ตัวช่วยที่แบ่งเวลาแทนเมื่อวลีขาด (ดู `hello/film.js`)
5. **Storyboard:** วางแต่ละบรรทัดเป็นภาพหนึ่งภาพ แล้ว `python kit/storyboard.py story01 th` ได้ `storyboard-th.jpg` ตรวจเองก่อนหนึ่งรอบ แล้วให้ผู้ใช้ตรวจ จุดนี้ตัดสินหน้าตาทั้งเรื่อง
6. **การเคลื่อนไหว:** เขียน `film.js` ตามหัวข้อด้านล่าง
7. **ตรวจภาพนิ่ง:** `cd story01/build/th && npx hyperframes lint && npx hyperframes snapshot --at <เวลา> --no-end -o <โฟลเดอร์ชั่วคราว>` เลือกเฟรมใกล้ท้ายทุกบรรทัดและเฟรมหลังเปลี่ยนฉากทุกจุด
8. **เรนเดอร์:** `npx hyperframes render --fps 30 --output raw.mp4` เรื่องตัวอย่าง 20 วินาทีใช้ราว 2 นาที 20 วินาที รันเบื้องหลังได้ แล้วบีบไฟล์ด้วย `ffmpeg -i raw.mp4 -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart <ชื่อคลิป>-v1.mp4` **เกรนทำให้ไฟล์ใหญ่มาก** ตัวอย่าง 20 วินาทีได้ 146 MB จากการเรนเดอร์ ที่ crf 19 ได้ 86 MB ที่ crf 21 ได้ 31 MB ที่ crf 23 ได้ 7.8 MB ที่ crf 26 ได้ 2.4 MB (ตัวเลขนี้ขึ้นกับฉากและโทนสี) ค่าที่แนะนำเริ่มต้นคือ 23 และต้องดูภาพเทียบเองว่าลายเกรนยังพอใจหรือไม่ วัดความดังจากไฟล์ที่บีบแล้ว ไม่ใช่จากไฟล์เสียงก่อนเรนเดอร์ เป้าหมาย -14 ถึง -16 LUFS (`ffmpeg -i <ไฟล์> -af loudnorm=print_format=summary -f null -`)
9. **ตรวจทุกเฟรม:** `python kit/frame_sheets.py <ไฟล์>.mp4 story01/frame-check` ได้แผ่นเฟรมเลขกำกับ อ่านให้ครบก่อนส่ง เจอปัญหาที่ภาพนิ่งท้ายบรรทัดไม่เห็น เช่น ป้ายที่ยังชัดอยู่ทั้งที่ฉากจางไปแล้ว

เก็บทุกเวอร์ชัน เขียน `-v2` ไม่ทับไฟล์ที่ผู้ใช้อาจเปิดอยู่

## ไฟล์ของระบบ

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `assets/figure.js` | ตัวละครตั้งค่าได้: `drawFig`, `figPose`, `figMix`, `figWalk`, `figHip` |
| `assets/set.js` | ชุดสีตามแนว `GENRES`, ห้องตัดขวาง, ของในฉาก, กล้อง `camIn`, `camOut`, `camAtTime` |
| `assets/look.js` | คำบรรยาย `captionTimes` `drawCaption`, เกรน, ขอบมืด, แสง `glow`, กากบาท, การปรับภาพกลางวัน `beginWorld` `endWorld` |
| `assets/cards.js` | การ์ดกฎ `drawRuleCard`, โทรศัพท์ `drawPhone`, ชื่อท้ายตอน `drawEndTitle`, ตัวช่วย `useGenre(GN)` |
| `kit/` | เครื่องมือสร้างคลิป ดูหัวข้อ "เริ่มโปรเจกต์" |
| `examples/hello/` | เรื่องตัวอย่างสามบรรทัดที่ใช้ครบทุกส่วน |

ใส่ไฟล์ใน `scripts` ของ `story.json` ตามลำดับนี้: `../shared/figure.js`, `../shared/set.js`, `../shared/look.js`, `../shared/cards.js` แล้วตามด้วยไฟล์ของเรื่องเอง (`props.js`, `film.js`) เรียก `useGenre(GN)` หนึ่งครั้งที่ต้น `film.js` เพื่อให้คำบรรยายและการ์ดใช้สีของแนวที่เลือก

**ห้ามตั้งชื่อตัวแปรหรือฟังก์ชันระดับบนสุดซ้ำกับ `kit/kit.js`** ถ้าซ้ำ หน้าเว็บจะขึ้น `render is not defined` เพราะไฟล์ทั้งไฟล์พัง ชื่อที่ชนบ่อย: `P`, `INK`, `stroke`, `trace`, `mix`, `out`, `back`, `ph`, `cl`, `io`, `lerp`, `rgb`, `txt`, `tag`, `paper`, `vignette` และชื่อทุกตัวใน `assets/` ให้ตั้งชื่อชุดสีของแนวว่า `GN` ไม่ใช่ `P`

## เริ่มเรื่องใหม่: ถามให้ได้ 4 เรื่องนี้

1. **แนว:** มีใน `GENRES` ไหม ถ้าไม่มีให้เพิ่มชุดสีใหม่ 1 ชุด
2. **ฉากเดียวของเรื่อง:** ต้องเป็นที่ที่เรื่องเกิดได้เกือบทั้งหมดและเห็นหลายพื้นที่พร้อมกัน เช่น บ้าน ตึก เรือ โรงเรียน หรือยานอวกาศ
3. **ตัวละคร:** ใครบ้าง และจดจำแต่ละคนจากรูปทรงกับสีอะไร
4. **เส้นต่อเนื่อง:** ของที่เห็นได้ทุกช็อตเพื่อบอกว่าเรื่องไปถึงไหนแล้ว เช่น ระดับน้ำ ไฟ นาฬิกา หรือแบตโทรศัพท์

ทำภาพรวมตัวละครกับฉากให้ผู้ใช้ตรวจก่อนลงมือเขียนการเคลื่อนไหว

## ตัวละคร

ทุกตัวใช้โครงและท่าร่วมกัน เปลี่ยนด้วย `spec` ที่เป็นข้อมูลล้วน จึงเพิ่มตัวละครได้ไม่จำกัดโดยไม่ต้องแก้โค้ดวาด

```js
const AUNT = { hairStyle: "bun", top: "dress", shirt: "#b8486a", shirtShade: "#90385a", hair: "#55504a", headR: 38 };
const KID = { headR: 42, torso: 66, upper: 40, fore: 38, thigh: 50, shin: 50, bodyW: 40, hairStyle: "spiky", bareLegs: true, accessories: ["cap"] };
const GHOST = { float: true, hairStyle: "ghost", eyes: "wide", skin: "#dfe6dc", shirt: "#e7ebe4", shirtShade: "#c2c9c0" };
drawFig(x, floorY - figHip(AUNT) * s, s, face, figPose({ mouth: 0.5, brow: 0.6 }), AUNT);
```

| ค่า | ตัวเลือก |
|---|---|
| สี | `skin`, `skinShade`, `hair`, `shirt`, `shirtShade`, `pants`, `pantsShade`, `shoe`, `line`, `accent`, `accentShade` |
| สัดส่วน | `headR`, `neck`, `torso`, `upper`, `fore`, `thigh`, `shin`, `armW`, `sleeveW`, `legW`, `shinW`, `bodyW` |
| ผม `hairStyle` | `short`, `long`, `bob`, `bun`, `spiky`, `bald`, `ghost` |
| ชุด `top` | `shirt`, `dress`, `robe` |
| ตา `eyes` | `dot`, `wide`, `hollow` |
| ของ `accessories` | `pack`, `cape`, `tie`, `glasses`, `moustache`, `beard`, `cap`, `hardhat`, `crown`, `catears` |
| พิเศษ | `float` ลอยไม่มีขา, `bareLegs`, และ `FIG_DARK` สำหรับคนหรือผีเงาดำ |

- **เด็ก:** ลำตัวและขาสั้นลง หัวใหญ่ขึ้น
- **คนตัวใหญ่:** เพิ่ม `bodyW`, `legW`, `armW` และเปลี่ยนตัวอื่นตามสัดส่วน
- **สัตว์ที่ยืนสองขา:** ใช้สีเดียวทั้งตัว กับ `bald`, `catears`, `top: "robe"`
- **ถ้าสิ่งที่ต้องการไม่มีในรายการ:** เพิ่มตัวเลือกในฟังก์ชันที่เกี่ยวข้องของ `figure.js` อย่าเขียนตัวละครแยกต่างหาก เพื่อให้ท่าใช้ซ้ำได้
- **จำง่ายเมื่อดูเล็ก:** ทดสอบตัวละครที่ขนาดเต็มตัวประมาณ 200 px ถ้าแยกกันไม่ออก ให้เปลี่ยนรูปทรงก่อนเปลี่ยนสี

**ท่า:** ใช้ `figMix` เปลี่ยนท่าโดยไม่ตัดกะทันหัน และ `figWalk` สำหรับการเดิน ทุกท่าต้องขึ้นกับเวลา ค่าในท่าได้แก่ `torso`, `head`, `armF`, `elbowF`, `armB`, `elbowB`, `hipF`, `kneeF`, `hipB`, `kneeB`, `blink`, `look`, `mouth`, `brow` ตรวจท่าที่สำคัญเป็นภาพนิ่งทุกครั้ง เพราะท่าที่ซ้อนกับของในฉากอาจอ่านผิดความหมาย

## ฉาก

```js
const GN = GENRES.ghost;                         // ไม่ใช่ P: kit.js มีฟังก์ชัน P อยู่แล้ว
useGenre(GN);
setSky(GN);
camIn(camAtTime(t, KEYS));
setBuilding(GN, 0, 0, [[900], [900]], 600);
setWindow(GN, 120, -440, 200, 200, false);
setDoor(GN, 760, -22, 110, 320);
drawFig(300, -22 - figHip(HERO) * 1, 1, 1, pose, HERO);
camOut();
```

- `GENRES` มี `disaster`, `ghost`, `comedy`, `scifi`, `period` และเพิ่มได้
- **ห้องต้องสูงอย่างน้อย 1.2 เท่าของตัวละครที่ขนาดจริง** ไม่อย่างนั้นหัวจะทับพื้นชั้นบน
- ฉากเดียวทั้งตอนทำให้ระดับน้ำ เงา และตำแหน่งของต่อเนื่องได้เอง การตัดไปที่อื่นควรเป็นการตัดสินใจที่ผู้ใช้เห็นด้วย
- ของเฉพาะเรื่องเขียนใน `props.js` ด้วยฟังก์ชันสั้น ๆ ที่รับเวลา ถ้าใช้ซ้ำหลายตอนค่อยย้ายมาไฟล์กลางพร้อมตั้งชื่อสี

## กล้อง

`cam = [zoom, worldX, worldY, screenX, screenY]` หมายถึงจุด (worldX, worldY) ไปอยู่ที่ตำแหน่งนั้นบนจอ ถ้าต้องหลบคำบรรยายหรือการ์ด ให้เปลี่ยนค่า screen ไม่ต้องย้ายของในฉาก

- เริ่มเคลื่อนตั้งแต่เฟรมแรก ห้ามเปิดด้วยภาพนิ่ง
- ช่วงเล่าเหตุการณ์ใช้ภาพกว้าง ส่วนอารมณ์และรายละเอียดซูมใกล้
- ใช้เวลาเลื่อน 0.8–2.4 วินาทีเป็นค่าเริ่มต้น

## โครงการเล่าที่ปรับตามแนว

| แนว | ฮุก | สิ่งที่คนดูติดตาม | ปิดตอน |

| ผี | สถานการณ์ผิดปกติ | ผีเข้าใกล้ กฎในเรื่อง | หักมุม และค้างปมของสาย |
| ตลก | ปัญหาที่ทุกคนรู้จัก | เรื่องบานปลาย | มุกท้าย |

ตารางนี้เป็นจุดเริ่มต้น ไม่ใช่สูตรตายตัว ตัวเลขหรือข้อเท็จจริงจริงต้องตรวจแหล่งก่อนใช้เสมอ ส่วนเรื่องแต่งต้องระบุว่าแต่ง และอย่าอ้างชื่อคนหรือสถานที่จริง

## ข้อมูลบนจอ

- **เฟรม:** 1080 × 1920, 30 fps
- **พื้นที่ปลอดภัย:** เว้นบน 140 px ล่าง 260 px ขวา 120 px
- **คำบรรยาย:** Kanit หนา 72 px ศูนย์กลาง y 1310 กว้างไม่เกิน 880 px ตัดวลีด้วยมือและห้ามตัดกลางคำ ห้ามวางสิ่งสำคัญไว้ที่ y 1250–1370
- **สีคำ:** ขาวทั่วไป สีเน้นของแนวคำสำคัญ และสีอันตรายของแนวคำอันตราย แต่ความหมายต้องอยู่ในคำเองด้วย
- **การ์ดกฎ:** x 110–970 เริ่ม y 210 จบเหนือ y 1200 ภาพประกอบต้องขึ้นพร้อมการ์ด ฉากหลังยังขยับ และเหตุการณ์สำคัญห้ามเกิดหลังการ์ด
- **ไฟกะพริบ:** ไม่เกิน 3 ครั้งต่อวินาที
- **ความรุนแรง:** ปรับตามแนว และถ้าไม่มีคำสั่งอื่น ไม่แสดงเลือด รอยไหม้ หรือภาพเสียชีวิต

## ของที่เคยพลาด

- ตั้งชื่อชุดสีว่า `P` ชนกับ `kit.js` ทำให้ `render is not defined` และสกิลนี้เคยเขียนตัวอย่างผิดแบบนี้เอง
- เรียกฟังก์ชันที่ไม่มีอยู่จริงในฉากท้าย ทำให้ชื่อเรื่องไม่ขึ้น ตรวจเฟรมสุดท้ายทุกครั้ง
- กล้องซูมใกล้จนตัวละครตัวหนึ่งหลุดจอ ทั้งที่บทกำลังให้สองตัวโต้ตอบกัน ต้องคำนวณว่าสองตัวอยู่ในกรอบพร้อมกัน
- ใช้กล้องมุมเดียวตลอดคลิปทำให้ภาพแบนและตัวละครเล็ก
- ไฟดับแล้วบางอย่างในฉากยังสว่างเท่าเดิม ต้องปรับภาพทั้งฉาก
- กระพริบหรือของเรืองแสงที่วาดก่อนปรับภาพจะขาวโพลน ให้วาดหลังปรับภาพ
- วาดท่าใหม่ซ้อนกับของในฉากจนอ่านผิดความหมาย
- ตัวละครวาร์ปข้ามจอหรือเปลี่ยนท่าทันที ต้องใช้ `figMix` และเดินตามระยะทาง
- ป้ายบนการ์ดทับหัวเรื่อง และข้อความในตัววัดล้นกรอบ
- ฉากสั่นแล้วเห็นขอบภาพ ต้องวาดฉากให้กว้างกว่าจอ

## การส่งงาน

ตรวจแผ่นเฟรมทุกแผ่นด้วย `kit/frame_sheets.py` และรายงานให้ตรงว่าตรวจกี่แผ่น ก่อนส่งมอบให้บอกผู้ใช้ด้วยว่ายังไม่ได้ดูการเคลื่อนไหวหรือฟังเสียงส่วนไหน และให้รายการสิ่งที่ผู้ใช้ควรดูเอง เรียงจากสำคัญที่สุด ถ้าเรื่องที่ทำเป็นตอนใหม่ของซีรีส์เดิม ให้ใช้โครงโฟลเดอร์เดิมของซีรีส์นั้น

ข้อความโพสต์เปิดด้วยคำถามและไม่เฉลยคำตอบ ภาพปกใช้เฟรมที่ตัวละครลืมตาและปิดคำบรรยาย

## ใช้อย่างรับผิดชอบ

- เนื้อหาที่แต่งต้องบอกคนดูว่าแต่ง และกฎในเรื่องต้องไม่หน้าตาเหมือนคำแนะนำความปลอดภัยจริง
- ตัวเลขหรือกฎที่เป็นข้อเท็จจริงต้องมีแหล่งที่ตรวจแล้ว ใส่ชื่อหน่วยงานเป็นตัวอักษร ไม่ใช้โลโก้จริง
- ไม่ใช้ชื่อคน สถานที่ หรือเหตุการณ์จริงในเรื่องแต่ง และไม่ผูกตัวละครผีหรือสัตว์ประหลาดกับกลุ่มคนจริง
- ตอนอัปโหลด ติ๊กว่ามีเนื้อหาที่สร้างด้วย AI เพราะเสียงพากย์เป็นเสียงสังเคราะห์
